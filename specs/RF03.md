# RF03 - Criar a entidade de usuário

O estudante deverá modelar a entidade de usuário do sistema utilizando os decorators do TypeORM (@Entity, @Column, etc.), contendo, no mínimo: identificador único (id), nome, e-mail (único), senha (armazenada com hash), perfil de acesso (role) e data de criação. Esta é, nesta etapa, a única entidade obrigatória do sistema.
