# REQUISITOS NÃO FUNCIONAIS (RNF)

**RNF01 - Aplicação executável via terminal:** A API deverá ser iniciada exclusivamente pelo terminal de comandos via scripts do package.json (ex.: npm run dev), escutando em porta configurável via .env.  

**RNF02 - Organização do código:** Código organizado em camadas (Routes, Middlewares, Controllers, Services, Repositories, Entities, Database, Utils), evitando arquivos monolíticos.  

**RNF03 - Padronização do código:** Nomes claros e padronizados para classes, interfaces, funções, variáveis e rotas.  

**RNF04 - Qualidade do código:** Baixo acoplamento, alta coesão e ausência de duplicações desnecessárias.  

**RNF05 - Segurança:** Senhas criptografadas com hash, tokens JWT com expiração e variáveis sensíveis isoladas em arquivo .env.  

**RNF06 - Portabilidade:** Execução correta em qualquer ambiente com os pré-requisitos especificados sem alterar código-fonte.  

**RNF07 - Uso obrigatório de TypeScript:** Tipagem estática consistente em todo o projeto. Proibido uso de JS puro ou tipo any indiscriminado.
