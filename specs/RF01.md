# MedClinic API: Instalação e Configuração do Projeto

## RF01 - Configurar o projeto Node.js com TypeScript e Express

O estudante deverá criar uma aplicação utilizando Node.js, TypeScript (obrigatório) e Express.js, contendo, no mínimo, os arquivos: package.json, tsconfig.json, README.md, .gitignore e src/server.ts. O projeto deverá possuir scripts para execução em ambiente de desenvolvimento e para build/execução em produção (ex: npm run dev, npm run build, npm start). Todo o código-fonte deverá ser escrito em TypeScript.

## ATENÇÃO ESPECIAL

Precisamos respeitar as regras de **Fluxo de desenvolvimento** exigidas pelo meu professor no projeto. Começando por:  
>_branch = main_  
>_commit = feat: cria estrutura inicial do projeto_

**NÃO EFETUE NENHUM COMMIT**  
A menos que eu peça, eu mesmo farei os commits.  

A estrutura inicial deverá ter como base a estrutura contida na pasta:  
_ambiente-configuraçoes\clinic-api

O projeto clinic-api contém a estrutura que preciso para a MedClinic API.  
Certifique-se de que tudo que levar o nome clinic-api seja alterado para medclinic-api, incluindo o nome do projeto no package.json, README.md e outros arquivos.

As pastas ambiente-configuraçoes e specs devem ser incluidas no .gitignore.
